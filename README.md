
# Дипломная работа: Автотесты для Кинопоиска
Проект представляет собой набор автотестов для проверки функциональности сайта «Кинопоиск» и его API. 
Тесты разделены на два слоя:
UI‑тесты — проверяют пользовательский интерфейс: ввод поисковых запросов (на кириллице и латинице), 
переходы по страницам (случайный фильм, расширенный поиск), открытие карточки фильма и валидацию заголовка.
API‑тесты — проверяют работу API Кинопоиска: поиск фильмов по названию (в том числе с несуществующим названием), 
поиск по жанру, валидацию структуры ответов и граничные случаи.
В проекте используется паттерн PageObject: вся логика взаимодействия со страницей и API вынесена в отдельные классы 
(SeachCinemaPage и KinopoiskApiClient), а тесты содержат только сценарии и проверки.

Для оформления отчётов применяется Allure: каждый шаг теста помечен декоратором allure.step, а сами тесты снабжены 
метаданными (title, description, severity, feature, story, mark).

## Структура проекта

Проект организован по модульному принципу для удобства поддержки и масштабирования:

final_proj/
├── pages/                # Page Objects (классы страниц)
│   ├── kinopoisk_page_API.py   # Логика работы с API
│   └── kinopoisk_page_UI.py    # Локаторы и методы UI-страниц
├── tests/                # Тестовые сценарии
│   ├── test_kinopoisk_API.py    # Тесты API (поиск фильмов, валидация JSON)
│   └── test_kinopoisk_ui.py     # UI-тесты (навигация, клики, проверки элементов)
├── allure-results/      # Результаты прогонов тестов (генерируется автоматически)
├── config.py             # Глобальные настройки и константы
├── pytest.ini            # Конфигурация pytest и Allure
├── requirements.txt      # Зависимости проекта
└── README.md            # Эта документация

Проект использует следующие технологии и синтаксис:

1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

## Требования (в проекте используются следующие технологии)

- Python 3.8+

- pytest

- selenium

- allure-pytest

## Конфигурация

Все параметры и тестовые данные вынесены в файл config.py:

BASE_URL — базовый URL сайта Кинопоиск.
BASE_URL_API — базовый URL API.
API_TOKEN — токен для доступа к API (в проекте указан тестовый токен).
SEARCH_TEXT_RUS, SEARCH_TEXT_ENG — поисковые запросы на кириллице и латинице.
GENRE_TEXT — запрос для поиска по жанру.
FAKEMOVIE — несуществующее название фильма для проверки граничного случая.

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.

## Запуск тестов

Режим  	          Команда	                           Описание
Все тесты	       pytest	                           Запускает все тесты (UI и API)
Только UI	       pytest -m ui	                     Запускает только UI‑тесты
Только API	       pytest -m api	                     Запускает только API‑тесты
Конкретный тест	 pytest tests/test_*.py::test_name	Запускает один указанный тест
С подробным логом	 pytest -v	                        Подробный вывод результатов
Allure‑отчёт	    allure generate ...	               Создаёт и открывает Allure‑отчёт

## Запуск тестов с формированием Allure отчета

1. Убедитесь, что Allure установлен.

2. Запустите тесты с командой:

 -  `pytest --alluredir=./allure-results` - запуск всех тестов

 -  `pytest test_kinopoisk_UI.py --alluredir=./allure-results` - запуск UI тестов

 -  `pytest test_kinopoisk_API.py --alluredir=./allure-results` - запуск API тестов

## Запуск просмотра с формиррованного отчета Allure

1. Команда для просмотра сформированного отчёта Allure `allure serve allure-results`

2. Сгенерируйте отчет с помощью команды `allure generate ./allure-results -o ./allure-report`.

3. Откройте отчет с помощью команды `allure open ./allure-report`.
